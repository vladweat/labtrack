## Утвержденные требования и проектные материалы

Документы v0.6.1 фиксируют требования и решения для синтетического MVP. Они не заменяют проверку текущего кода, миграций и runtime API:

- [Реестр решений](20-decisions-v061.md) — принятые продуктовые решения.
- [Исключения передачи](21-custody-exceptions-v061.md) — нормативные правила инцидентов и исключительной приемки; соответствующая логика реализована в backend.
- [Offline-целостность](22-offline-integrity-v061.md) — требования к снимкам, конфликтам и replay; реализация кратко описана в [offline guide](offline-sync.md).
- [Модель данных v0.6.1](23-data-model-v061.md) — проектные требования и ограничения схемы, не актуальный ERD.
- [API и операции v0.6.1](24-api-and-operations-v061.md) — продуктовые требования; точные runtime маршруты доступны в запущенном FastAPI `/docs`.
- [План проверки](25-test-plan-v061.md) — приемочные требования, а не отчет о текущем запуске тестов.

Доступные ранние материалы v0.5 и v0.6 сохранены как история проектирования; актуальная краткая навигация приведена выше. [OpenAPI v0.6.1](../openapi/labtrack-v1.json) — исторический проектный черновик, не runtime-контракт. Генерация текущей схемы из `app.openapi()` и известные различия описаны в [документе API](api.md).
